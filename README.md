## 思路记录

**简单题不硬写** —— 没有坑的题就不填，空白比废话诚实。

| 题号 | 一句话总结 |
|---|---|
| **P1046** 陶陶摘苹果 | 用 for 循环批量读入数组（因为 x 最后才输入，必须先存）；**只统计个数时不要排序**，原代码的 sort 是多余的 |
| **P1888** 三角函数 | 正弦 = 最短边 / 最长边再约分；**手写 gcd（辗转相除）**，`std::gcd` 需 C++17 |
| **P1424** 小鱼的航程 | **一题两解**：`_数学法` 整除 + 分类做到 O(1)；`_模拟法` 逐天走 O(n) |
| **P5714** 肥胖问题 | 6 位**有效数字**用 `setprecision(6)`，**绝不能加 `fixed`** |
| **P5716** 月份天数 | 2 月单独判闰年，其余查表；`%4==0 && %100!=0 || %400==0` |
| **P5710** 数的性质 | 把 `bool` 直接相加，判断"恰好满足几条" |
| **P5711** 闰年判断 | `&&` 优先级高于 `or`，但加括号更安全 |
| **P2433** 小学数学 N 合一 | 题干含十几个独立子问题，逐个处理 |
| **P4414** ABC | **一题两解**：`_极值法` 先定 A/B/C 再按字母 if 输出；`_查表法` 排序后用 `ch-'A'` 当下标查表。核心是「存」和「取」分离 |
| **P1055** ISBN 号码 | 整串读入，`continue` 跳过 `-`，用计数器 `w` 记「第几个数字」，9 个数字乘 1~9；余 10 记 `X`；错误时只改 `s[12]`，横杠原样保留 |
| **P5718** 找最小值 | 读入后 `sort` 取 `a[0]` 最直接；但**找最小值不必排序**，边读边比较即可 O(n)、还省数组 |
| **P5719** 分类平均 | 平均数 = 和 ÷ 个数，边循环边累加，**不用存数组**；A 是 `i%k==0`、B 是其余；`i` 从 1 到 n；`cout << fixed << setprecision(1)` |
| **P5720** 一尺之棰 | 纯模拟：每天 `a /= 2`，天数从 1 起；`a == 1` 要特判，否则 do-while 会除以 0 后死循环 |
| **P5721** 数字直角三角形 | **for 内外循环**：外层管行（`i` 从 n 到 1），内层管每行个数（`j` 到 `i`）；`setw(2)` 只对下一次输出生效，`setfill('0')` 一次即可 |
| **P1980** 计数问题 | **拆位统计**：`while (b > 0) { c = b % 10; b /= 10; }` 逐位比对；整数拆位天然不数前导零，`x = 0` 也正确 |
