## 约定

- 文件名 `题号_题目名.cpp`，一题多解加后缀
- 笔记写在文件**开头**；写在 `main` 的右大括号之后会编译失败
- **新建文件先复制 `00_模板.cpp`**
- **变量声明时就赋值** —— 局部变量不会自动清零；**全局数组才会默认清 0**
- **`if`/`for`/`while` 里不要写赋值** —— 开 `-Wall` 让编译器帮你查
- **互斥的多条分支用 `else if` 链**
- **数组开固定大小** —— 不用 `int a[n]`
- **`if` 后面记得 `else`**
- **整除要小心括号** —— `(n+1)/2` 不是 `n + 1/2`
- **倒序输出从 `i-1` 开始**
- **不要把输入变量当循环变量用**
- **枚举所有对用 `j = i + 1`**
- **`q`/`n` 次操作的读入写在循环里面**
- **每张/每次的计数变量要在循环开头清 0**
- **算出来的变量，后面一定要用到**
- **输出时用循环变量（`i`、`j`），不要用已经失效的坐标变量（`x`、`y`）**
- **判断「走不了」用 `||`，判断「能走」用 `&&`**
- **三层以上嵌套循环加大括号**
- **提交前两个样例都要跑**，测试数据要覆盖每个分支
