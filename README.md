## 约定

- 文件名 `题号_题目名.cpp`，一题多解加后缀（如 `P1424_小鱼的航程_数学法.cpp`）
- 笔记写在文件**开头**；写在 `main` 的右大括号之后会编译失败
- **新建文件先复制 `00_模板.cpp`**，里面有写代码前的三条自检
- **变量声明时就赋值** —— 局部变量不会自动清零

## 学到了什么

| 题号 | 一句话 |
|---|---|
| P1423 | 递推用 `dist *= 0.98`，不要 `pow` 每轮重算；浮点数不能 `==` |
| P2669 | 双刹车（本档上限 + 总额度）；while 管档、for 管天 |
| P1035 | `1.0/n` 不能写 `1/n`；次数未知用 `while` |
| P5722 | 循环累加不用数组；先读入 n 再声明数组 |
| P5726 | 去掉最高最低 → 分母是 n-2；一题两解 |
| P5724 | 极差也是扫一遍；别用 sort、别用 VLA |
| P5718 | 找最值扫一遍 O(n)，不用排序 |
| P1980 | 拆位：`while(b>0){ b%10; b/=10; }` |
| P5719 | 平均数不必存数组，直接 `sum += i, cnt++` |
| P5720 | do-while 至少执行一次，边界要特判 |
| P5721 | 双层循环打图形：外层管行、内层管数 |
| P1888 | 手写 gcd；`min({a,b,c})` 取三数极值 |
| P1424 | 一题两解：数学法 O(1) / 模拟法 O(n) |
| P5714 | 6 位有效数字用 `setprecision(6)`，不能加 `fixed` |
