## 约定

- 文件名 `题号_题目名.cpp`，一题多解加后缀
- 笔记写在文件**开头**；写在 `main` 的右大括号之后会编译失败
- **新建文件先复制 `00_模板.cpp`**
- **变量声明时就赋值** —— 局部变量不会自动清零
- **变量只在它声明的那对大括号内有效**（作用域）
- **`if`/`for`/`while` 里不要写赋值**（`if (x = 5)` 是赋值，永远为真）
- **不够/找不到时用 `return 0`**，不要用 `break`
- **提交前两个样例都要跑**
- **`return` 的值要放在"条件全部检查完"之后**
- **先搭括号骨架，再往里填代码**

## 枚举法的四要素

| 要素 | 问什么 |
|---|---|
| ① 枚举什么 | 哪个变量当"试的对象" |
| ② 范围 | 从哪到哪（能不能缩小？） |
| ③ 验证 | 怎么判断这个候选合法 |
| ④ 停止 | 什么时候收手 |

**三个通用加速手段：消元（P4956）、范围缩小（P1075）、构造候选（P1217）。**
