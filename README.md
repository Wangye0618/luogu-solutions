## 刷题计划：两段式

| 阶段 | 时间 | 目标 | 需要「专题」吗 |
|---|---|---|---|
| **第一段 · 工具期** | 现在 → 入门6 完成 | 数组 / 字符串 / 函数 / 结构体，练写法 | ❌ 不需要，多写就熟 |
| **第二段 · 专题期** | 入门6 之后 | 【算法1-x】按知识点逐个吃透 | ✅ **一个专题 2–3 天，期间不碰别的** |

### 第一段的做法

按题单顺序走，**不跳题**。工作日 2 题 / 周末 4 题。
卡住 → 自己想 20 分钟 → 问 AI → **关掉重写一遍**。

### 第二段的做法

```
第 1 天 · 学：看套路 20min + 例题 1 道 + 同类 1 道
第 2 天 · 练：同类 2 道（独立，不看题解）
第 3 天 · 固化：重做错题 + 变式 1 道（仅难题专题）
```

**铁律：同一个专题期间，绝不碰别的专题的题。**
不属于当前专题的题 → 记到「待学清单」，等排到再学。

### 一个专题算「过了」的三条标准

1. 能独立做出 **3 道同类题**（不看题解）
2. 能一句话说清「**什么信号下用它**」
3. **一周后还能默写出模板**

三条全满足才算过。只满足 ① 只是「会这几道题」，换个马甲还是不会。
