## 学到了什么

| 题号 | 一句话 |
|---|---|
| P5722 | 循环累加不用数组；**先读入 n 再声明数组**，否则是 UB |
| P5726 | 去掉一个最高一个最低 → 分母是 **n-2**；一题两解：排序法 / 扫描法 |
| P5724 | 极差也是扫一遍；**别用 sort、别用 `int a[n]`（VLA）** |
| P5718 | 找最值扫一遍 O(n) 就够，不用排序 |
| P1980 | 拆位：`while(b>0){ b%10 判断; b/=10; }`，整数拆位不会多数前导零 |
| P5719 | 平均数不必存数组，循环里直接 `sum += i, cnt++` |
| P5720 | do-while 至少执行一次，`a==1` 这类边界要在循环外先特判 |
| P5721 | 双层循环打图形：外层管行、内层管每行几个数 |
| P1888 | 手写 gcd（辗转相除）；`min({a,b,c})` 一行取三数极值 |
| P1424 | 一题两解：数学法 O(1) / 模拟法 O(n) |
| P5714 | 6 位有效数字用 `setprecision(6)`，**不能加 `fixed`** |
