## 约定

- 文件名 `题号_题目名.cpp`，一题多解加后缀
- 笔记写在文件**开头**；写在 `main` 的右大括号之后会编译失败
- **新建文件先复制 `00_模板.cpp`**
- **变量声明时就赋值** —— 局部变量不会自动清零
- **变量只在它声明的那对大括号内有效**（作用域）
- **`if`/`for`/`while` 里不要写赋值**（`if (x = 5)` 是赋值，永远为真）
- **数组开固定大小** —— 不用 `int a[n]`（变长数组非标准，且下标只到 n-1）
- **数组开大一点** —— `int a[100]` 配 `i <= 100` 就是越界
- **`if` 后面记得 `else`** —— 不加就是"两步合一"，会吃掉中间结果
- **倒序输出从 `i-1` 开始** —— `i` 是下一个空位
- **不要把输入变量当循环变量用** —— 另开一个
- **枚举所有对用 `j = i + 1`** —— 不然每对数两次
- **`q`/`n` 次操作的读入写在循环里面** —— 写在外面就是"同一个操作做 q 遍"
- **每张/每次的计数变量要在循环开头清 0** —— 否则会接着上一轮继续加
- **坐标从 0 还是 1 开始，看题目**，不要自己换算
- **三层以上嵌套循环加大括号**
- **不够/找不到时用 `return 0`**，不要用 `break`
- **输入输出方向：`cin >> x`，`cout << x`**
- **提交前两个样例都要跑**
- **`return` 的值要放在"条件全部检查完"之后**
- **先搭括号骨架，再往里填代码**
