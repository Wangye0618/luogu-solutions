## 刷题方法

每道题走四步，**第 3 步是唯一真正涨功力的环节**：

1. **先自己想 15 分钟** —— 不许一上来就看题解
2. 卡住 → 看题解，理解思路
3. **关掉题解，从空白文件重写一遍** —— 跳过这步等于没做
4. 记一句「错在哪 / 学到什么」，写到下面的「思路记录」里

用**周总量**考核，不用「每天必做 N 题」考核。遇到难题做了 40 分钟，只做 1 题也算达标。

## 思路记录

每遇到想了很久、或学到新技巧的题，在这里写一句自己的总结。
**简单题不硬写**——没有坑的题就不填，空白比废话诚实。

| 题号 | 一句话总结 |
|---|---|
| **P1424** 小鱼的航程 | **一题两解**：`_数学法` 用整除 + 四种边界情况做到 O(1)；`_模拟法` 逐天走 O(n)。前者快、后者好写 |
| **P5714** 肥胖问题 | 6 位**有效数字**用 `setprecision(6)`，**绝不能加 `fixed`** —— `fixed` 会把精度改成"小数点后位数" |
| **P5716** 月份天数 | 2 月要单独判断闰年，其余月份查表；闰年规则 `%4==0 && %100!=0 || %400==0` |
| **P5710** 数的性质 | 把 `bool` 直接相加来判断"恰好满足几条"，比写一堆 `if` 干净 |
| **P5711** 闰年判断 | `&&` 优先级高于 `\|\|`，但**加括号更安全**，别靠记忆 |
| **P2433** 小学数学 N 合一 | 题干包含十几个独立子问题，逐个处理即可 |

## 目录结构

```
luogu-solutions/
├── 01_入门1_顺序结构/
├── 02_入门2_分支结构/
├── 03_入门3_循环结构/
```

文件名格式：`题号_题目名.cpp`（例如 `P5703_苹果采购.cpp`），按题号自动排序。
同一题有多种解法时加后缀：`P1424_小鱼的航程_数学法.cpp`、`P1424_小鱼的航程_模拟法.cpp`。

## 代码规范

```cpp
// 洛谷 Pxxxx 题目名
// https://www.luogu.com.cn/problem/Pxxxx
// 备注：（只在有坑 / 有技巧时写，简单题留空）

#include <bits/stdc++.h>
using namespace std;
int main()
{
    // 4 空格缩进，内部不留空行
    return 0;
}
```

**注意：笔记写在文件开头，不要写在末尾** —— 写在 `main` 的 `}` 之后会导致编译失败。
